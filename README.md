# Traducteur

Traduis un texte entre de nombreuses langues dans NeoBase, avec détection automatique de la langue.
Service MyMemory, gratuit et sans compte.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Traducteur → Installer**.

Développer un plugin : voir le [SDK NeoBase](https://github.com/NDesumeur/neobase-sdk).
